# Лабораторная работа по управлению фитнес клубом

Основной отчёт — report.md. Он оформлен по разделу 6 методички: титульные сведения и роли, разделы 1–9, источники и приложение. Для просмотра откройте report.md в VS Code и выберите Open Preview.

В assets находятся три изображения BPMN и общий редактируемый файл to-be.bpmn. В редакторе BPMN выберите нужную диаграмму: запись, покупка абонемента или регистрация посещения. Папка assets должна оставаться рядом с report.md.

defense-notes.md — отдельная шпаргалка; не является частью основного отчёта.

Перед сдачей впишите группу и преподавателя. Вариант 11 — управление фитнес-клубом. Не заданные исходные параметры обозначены как учебные допущения. Для сдачи поместите report.md и assets в папку ветки своего репозитория.
